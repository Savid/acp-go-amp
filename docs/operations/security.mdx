## Managed containment

Each session and probe uses a private HOME/XDG residence under `WithScratchDir`.
Settings, MCP configuration, seed files, and browser launchers are complete
before `HostAuthority.PrepareNativeTree`.

Every managed process starts through `StartNative` with host stdio. The adapter
performs no residence path access until `ReclaimNativeTree` succeeds.
Cancellation and shutdown call `Revoke`, then wait. Uncertain settlement fails
closed with `ErrContainmentIncomplete`; `ErrNativeTreeBusy` identifies a live
lease. Nil or unusable authority fails before mutation or launch, with no direct
fallback. Omitted `WithHostAuthority` selects ordinary same-identity execution.

## Secrets and local inputs

Hosted provider login is ordinary-only and uses its own isolated residence.
Its executable audit completes before that residence and browser shim are
created; native settlement precedes the secret read. Managed provider auth
supports the manual API-key method. The provider-auth
ledger and native residence contents never enter the session store. The session
manifest does persist the complete session environment; a store is
therefore secret-bearing when that environment carries `AMP_API_KEY`.
`GOTRACEBACK`,
`AMP_DISABLE_SECRET_REDACTION`, and private adapter variables are scrubbed.
`WithInputHandoffRoot` permits digest-verified image reads below an absolute
read-only root.

With host authority, the adapter pins that read-root descriptor before any
native preparation and checks directory identities and ancestors against the
entire scratch parent. Overlap is refused as `path_not_allowed` when a handoff
is requested. Use a dedicated read directory outside `WithScratchDir` (or the
system temp directory when scratch is omitted). Reads use the retained
descriptor until `Agent.Close`, including after session reclaim.

The host must preserve directory identities and their disjointness throughout
the Agent's lifetime, including pre-existing mount/volume aliases and protection
against native replacement of roots or their ancestors. Initial identity checks
do not establish this host filesystem guarantee. Malformed declarations and
media/size pregates remain ahead of file reads.
