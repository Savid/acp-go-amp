## API key

Set `AMP_API_KEY` for authenticated turns. The adapter scrubs it from login.

## Provider account login

With `WithProviderAuthRoot`, eight session-scoped `_amp/auth/*` methods are
advertised, including `_amp/auth/credential`. Hosted login runs through host
authority in its own prepared residence. `Wait` settles the process, reclaim
precedes the secret read, and the credential is returned once. The values-free
ledger stores no credential and disconnect performs no Amp-side mutation.
