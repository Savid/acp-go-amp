---
title: Install
description: Install the library or standalone command.
---

## Standalone command

```sh
go install github.com/savid/acp-go-amp/cmd/acp-go-amp@latest
```

Pass the Amp executable with `-path`. The command uses ordinary execution.

## Go library

Add `github.com/savid/acp-go-amp` to an embedding module and configure the Amp
executable with `WithExecutablePath`. Managed hosts also supply
`WithHostAuthority`.
