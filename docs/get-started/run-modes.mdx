---
title: Run Modes
description: Standalone ordinary execution and embedded managed execution.
---

## Ordinary execution

The command runs ordinarily as its current identity:

```sh
acp-go-amp -path amp -scratch-dir /path/to/scratch
```

Omitting `WithHostAuthority` selects the same behavior for an embedded agent.

## Managed execution

Embedded `Serve` or `NewAgent` may add `WithHostAuthority`. Managed mode
routes every probe, prompt, helper, login, and browser descendant through the
authority. Settings, MCP files, and seed files are complete before preparation.
