## Ordinary execution

The command runs ordinarily as its current identity:

```sh
acp-go-amp -path amp -scratch-dir /path/to/scratch
```

Omitting `WithHostAuthority` selects the same behavior for an embedded agent.

## Managed execution

Embedded `Serve` or `NewAgent` may add `WithHostAuthority`. Managed mode
routes every probe, prompt, helper, login, and browser descendant through the
authority. Settings, MCP files, and seed files are complete before preparation.

```go
err := ampacp.Serve(ctx, input, output,
	ampacp.WithExecutablePath("amp"),
	ampacp.WithScratchDir("/var/lib/my-host/amp-scratch"),
	ampacp.WithHostAuthority(authority),
)
```

The authority is mandatory once supplied. An unavailable authority, unusable
process streams, or uncertain containment fails closed without an ordinary
launch fallback.

`NativeEnvironment()` supplies the managed base environment. Ordinary execution
uses the adapter's own process environment, or the block `WithAmbientEnvironment`
supplies in its place, filtered the same way. `WithEnv` overlays that base, then the
prompt's session environment overlays it, including a complete raw `PATH`.
Other native operations receive only the session's `AMP_API_KEY` and `AMP_URL`
over the static base. The adapter applies its fixed isolation values and
scrubs `GOTRACEBACK`, `AMP_DISABLE_SECRET_REDACTION`, and private adapter
variables before passing a sorted effective environment to the native process.
Session values are persisted in the manifest for later load and resume.

## Flag and option equivalents

| Flag | Go option |
| --- | --- |
| `-path` | `WithExecutablePath` |
| `-home` | `WithHome`, which Amp rejects when non-empty |
| `-model` | `WithDefaultModel`, which Amp rejects when non-empty |
| `-scratch-dir` | `WithScratchDir` |
| `-provider-auth-root` | `WithProviderAuthRoot` |
| `-provider-auth-direct-home` | `WithProviderAuthDirectHome`, which Amp rejects when non-empty |
| `-seed-file` | `WithSeedFiles` |

`-debug` configures the command's logger and `-version` prints the binary
version. Embed-only options, including `WithHostAuthority`, session stores,
turn and concurrency limits, image limits, and telemetry providers, have no CLI
flag.

See [Security](/docs/operations/security) for preparation, launch, settlement,
reclaim, and authority-loss behavior.
