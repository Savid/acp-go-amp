## Transport

`acp-go-amp` serves ACP JSON-RPC on stdin/stdout; diagnostics use stderr.

## Flags

| Flag | Purpose |
|---|---|
| `-path` | Amp executable path. |
| `-home` | Unsupported. |
| `-model` | Unsupported model override. |
| `-scratch-dir` | Parent for isolated native HOME/XDG state. |
| `-provider-auth-root` | Provider-auth ledger root; see `WithProviderAuthRoot`. |
| `-provider-auth-direct-home` | Unsupported direct-home gate. |
| `-seed-file relative=host-file` | Copy a file before preparation. |
| `-debug` | Debug logging. |
| `-version` | Print version and exit. |

## Managed hosts

Managed execution is embed-only through `WithHostAuthority`.
