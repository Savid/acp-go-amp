## Host authority

Use `NewAgent` or `Serve`. `WithHostAuthority` enables managed execution:

```go
type HostAuthority interface {
    NativeEnvironment() map[string]string
    PrepareNativeTree(context.Context, string) error
    ReclaimNativeTree(context.Context, string) error
    StartNative(context.Context, NativeRequest) (NativeProcess, error)
}
```

`NativeProcess` exposes host stdin/stdout/stderr, `Wait`, and `Revoke`.
`NativeRequest` carries executable, arguments, environment, and working
directory; `NativeResult` carries exit code, signal, and revoked state.

The sentinels are `ErrHostAuthorityUnavailable`,
`ErrContainmentIncomplete`, and `ErrNativeTreeBusy`. Supplied nil or unusable
authority fails before mutation or launch. Omitted authority uses ordinary
same-identity execution.

## Options

Important options include `WithExecutablePath`, `WithScratchDir`,
`WithInputHandoffRoot`, `WithProviderAuthRoot`, `WithEnv`,
`WithSeedFiles`, `WithSessionStore`, `WithConcurrencyLimits`,
and `WithImageLimits` (including `MaxOutputBytesPerToolCall`).
