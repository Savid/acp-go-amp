## Host authority

Use `NewAgent` or `Serve`. `WithHostAuthority` enables managed execution through
[HostAuthority](https://pkg.go.dev/github.com/savid/acp-go-amp#HostAuthority).
`NativeEnvironment` supplies the base environment; `PrepareNativeTree` and
`ReclaimNativeTree` bracket each isolated residence, and `StartNative` launches
every native child. See [Run modes](/docs/get-started/run-modes) for environment
overlays and an embedding example.

`NativeProcess` exposes host stdin/stdout/stderr, `Wait`, and `Revoke`.
The append-log members are part of the host interface; this adapter does not
invoke them: it mirrors Amp stream-JSON frames through `SessionStore`.
`NativeRequest` carries executable, arguments, environment, and working
directory; `NativeResult` carries exit code, signal, and revoked state.

The sentinels are `ErrHostAuthorityUnavailable`,
`ErrContainmentIncomplete`, and `ErrNativeTreeBusy`. Supplied nil or unusable
authority fails before mutation or launch. Omitted authority uses ordinary
same-identity execution.

## Options

Important options include `WithExecutablePath`, `WithScratchDir`,
`WithInputHandoffRoot`, `WithProviderAuthRoot`, `WithEnv`,
`WithSeedFiles`, `WithSessionStore`, `WithConcurrencyLimits`,
and `WithImageLimits` (including `MaxOutputBytesPerToolCall`).
`ValidateAmpSessionMeta(meta)` returns the refusal a session-establishing
request carrying that `_meta` map would receive, or nil, without an agent;
see [Metadata](/docs/reference/meta).

`WithEnv` is the static Agent-scoped environment. Names follow the session `env` rule with `PATH` allowed: a key is non-empty and free of `=` and NUL, the value is free of NUL, the injection names `NODE_OPTIONS`, `BASH_ENV`, `ENV`, and any `LD_` or `DYLD_` prefix are refused under the platform identity, the private adapter namespace is refused under every spelling, and two spellings of one Windows variable are refused; a refusal fails Agent construction.

`WithAmbientEnvironment` replaces the adapter's own process environment as the block ordinary execution inherits from. The same scrub applies to it, and `WithEnv` and the session environment overlay it; a supplied map is folded in sorted key order. Nil inherits from the adapter's process; an empty map inherits nothing. An entry that could not be an environment entry fails Agent construction. Every mode validates it; managed execution reads nothing from it.

## Image limits

`WithImageLimits` accepts `ImageLimits` with these decoded-byte budgets:

| Field | Default |
| --- | --- |
| `MaxInputBytesPerImage` | 6 MiB |
| `MaxInputBytesPerPrompt` | 6 MiB |
| `MaxOutputBytesPerImage` | 6 MiB |
| `MaxOutputBytesPerToolCall` | 6 MiB |

A zero field disables that configured budget; Amp's smaller native input
envelopes and the adapter's hard output bound still apply. See
[Image input](/docs/features/models-config#image-input) and
[Image output](/docs/reference/updates#image-tool-content).

## Quota types

`RateLimitsMethod` names `_amp/rateLimits`, dispatched through
`Agent.HandleExtensionMethod`. `RateLimitsRequest` selects `providerId` and
optional `sessionId`; `RateLimitsResponse` contains `providerId`, `availability`,
optional `reason`, and `pools`. `RateLimitPool`, `RateLimitWindow`,
`RateLimitBalance`, and `RateLimitMoney` describe the normalized observations.
Optional numbers use pointers so measured zero remains present. See
[Rate limits](/docs/reference/acp-methods#rate-limits) for selection and availability.

`WithAmpDirectAPI(bool)` configures `Options.DirectAPI`, enabled by default.
It controls the on-demand native account read and does not change prompt
authentication. A measurement needs an addressed live session with a delivered
`AMP_API_KEY`; the native command resolves that session's deployment and settings.
